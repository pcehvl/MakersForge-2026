Choose your track

Product loop: OpenCode in both tracks. You work with the Product Assistant in OpenCode to frame the product and write the specs. Only the execution loop – where the code is built – differs.

Main track

OpenCode

Both loops run in OpenCode on your own machine.

  • Product loop: OpenCode (Product Assistant)
  • Execution loop: OpenCode (Planner and Coder), locally
  • Supabase, Pull Requests, deploy with Vercel
  • Free: uses free models in OpenCode
  • Setup: about 60–90 minutes
Go to the OpenCode track → Lovable track

OpenCode + Lovable

OpenCode runs the product loop, Lovable builds – connected through Lovable's MCP server.

  • Product loop: OpenCode (Product Assistant) – same as the main track
  • Execution loop: Lovable, driven from the Lovable chat
  • /handover and /return between the loops, publish in Lovable
  • Can cost money: Lovable usage depends on your plan
  • Setup: about 45 minutes, only Git and OpenCode locally
Go to the Lovable track →
